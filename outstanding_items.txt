  underhand throw + holding idle), gathering / foraging (pick up, kneeling pick-up), mining (pickaxe), woodcutting
  (chopping), crafting (hammering at an anvil, working at a table, kneeling / sitting work).

  reaction, dodge; emotes (wave, bow, cheer, dance) for /emote commands later. 2-3 variants of common actions.

  random (tools/make_animation_pack.gd). Next: the Mixamo pack through the same tool (a Mixamo bone-name map), locomotion

- Locomotion by body type: the user has women's, men's and heavy-race walk / run sets; name them by type and map them
  to races and sexes (women / men / heavy = ogre, troll, maybe half-orc and dwarf).

- Ranged (archery) is mostly for the non-magic fighters: Blademaster and Woodstalker (the archery skill is already in
