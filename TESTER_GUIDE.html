Aldenexia: Lightfall · Playtest

Welcome to the desert of Lumora, tester!

Thank you for helping test Aldenexia: Lightfall. This page covers getting in, the handful of keys worth knowing, and how to send a report the developer can actually act on. Things will break — that's the point. Tell us when they do.

Getting in

  1. Download the game

    Open the download page: gofile.me/6Jpm4/4Wu7E5z7O. It shows two folders, Windows and Linux. Select the one for your computer and click Download folder — the whole folder downloads as a single .zip file.

  2. Extract it, then run it

    Windows: right-click the zip, choose Extract All… into its own folder (the game won't run from inside the zip), then run Aldenexia_Lightfall.exe and keep the other files next to it. Windows may warn about an unrecognised app — choose More info → Run anyway.

    Linux: extract the zip into its own folder (unzip or your file manager's Extract Here), then run ./Aldenexia_Lightfall.sh from that folder. If it won't start, make it runnable first: chmod +x Aldenexia_Lightfall.sh Aldenexia_Lightfall.x86_64.

    Both folders include NDA.txt — read it here too.

  3. Choose the public test server

    On the main menu, choose Join a Server and select test-us-west from the list (it used to be called test-public). (Multiplayer on the main menu is for games on your own home network (LAN), not the public test; ignore test-us-west-lan too — that is the same server reached from the developer's own network.)

  4. Update if asked

    If the server runs a newer build, press Download update. The game restarts itself into the new version — updates are small and only the first install is a big download.

  5. Log in to your account

    Type an account name and password, then press Log In. First time? Type the password twice and press Create Account instead. Account names use letters and numbers only (2–16), and the password needs at least 4 characters. One account holds up to 8 characters, and it works on any computer, even two at once. Already had a character from before accounts? The developer has already moved it into an account named after it (same password). You can also use Add Existing Character with its old name and password.

  6. Make your character

    Your characters are listed with their portrait, level, class and zone. Press + Create New Character to make one. A character has one name, letters only; at level 10 you can add a surname with /surname Name.

  7. Enter the world

    Pick a character and press Enter World (or double-click it). New characters start outside Lumora's gate.

Keep it between us

Lightfall is unreleased. The game folder includes NDA.txt (the full text is below) — by downloading, installing or playing the test build you agree to it. In short: no public screenshots, videos or streams without asking first, and don't pass the game, the download link or the server address to anyone who wasn't invited. Talking about it with the other testers is fine.

What to look at

  • How your class feels through the first levels — too strong, too weak, anything that never seems to work.
  • Quests (J) — talk to the guards and the wandering merchant, and read the note at the wrecked wagon.
  • Crafting & gathering — buy a kit or tools from the vendors, gather, craft, and see what your recipe book (L) fills in.
  • Playing together — grouping, trading, the bank, dropping items for each other.
  • Sound and music — anything too loud, too quiet, or missing.
  • Anything confusing. If you didn't know what to do next, that's a finding too.
