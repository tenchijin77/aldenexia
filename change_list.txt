how to rig a new character model:
(see chat for the full walkthrough — short version below)
-download/build the base mesh (Meshy or similar), export as FBX
-go to mixamo.com, upload the FBX to auto-rig it (needs a T/A-pose; only accepts .fbx/.obj, not .glb — export as FBX first if needed)
-download the rigged character itself once "With Skin" — this is the base model file
-download every other animation you want (idle/walk/run/jump/sit/attack/death/etc.) "Without Skin" (motion-only, much smaller, retargets onto the skin you already have)
-drop everything for one character into its own folder under models/<Character Name>/ (matches the Human Female / Human Male / Troll Male pattern)
-tell Claude the folder's ready — it needs one editor import pass (headless, automatic) then builds a merged AnimationLibrary + wires the race/sex into player3d.gd's CHARACTER_MODELS the same way as the last three
-texture note: don't bother fighting Blender's FBX export to embed the texture — it's been unreliable every time. Just make sure the real texture PNG is sitting in the same folder as the FBX; the game applies it directly as a runtime material override instead of depending on the FBX carrying it
-if you want a second attack animation, look for something like "Standing Melee Attack Downward" in Mixamo in addition to "Standing Melee Attack Horizontal" (or vice versa) — that's the pair the male model uses for its two random swings
