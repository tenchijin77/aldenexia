ALDENEXIA: LIGHTFALL — TESTING LOG
================================================================================
What this is: one place that records what playtesting found and what we did about it.
Class-specific findings go under that class's heading; everything that isn't tied to a class
goes in GENERAL. Every entry says WHO found it, WHAT, its STATUS, and where the fix lives.

How to add a test (Claude keeps this file up to date as issues are reported and fixed):
  1. Add a block to TEST SESSIONS: date, testers, and the character + class each one played.
  2. File each issue under its class heading (or GENERAL) as:
       - [STATUS] what was seen ........ (found by: T# / who)  -> fix or decision, file/section
  3. Change the STATUS when it moves. Statuses:
       OPEN            reported, not looked at yet
       DECISION        investigated; waiting on a design decision
       IN PROGRESS     being built
       FIXED           built and verified (how it was verified is in change_log.txt)
       NOT A BUG       working as designed (why is noted)
  Fix details live in change_log.txt (under the same date); design notes in game_flow.txt.

Combat and stats
- [FIXED]  Melee hit chance far too low at level 1 (about 20%, ~30 s to land a hit) while spells one-shot
           everything (found by: T0). Combat numbers now live in Data/combat_balance.json (player_hit_bonus 35,
           player_spell_damage_mult 0.5, monster HP/damage +12% per level above base). change_log: COMBAT TUNING.
- [FIXED]  Weapon skill only applied at the first skill-up; saved item copies carried old skill names
           (found by: T0). Skill synced after equipment loads, legacy names migrated. change_log: WEAPON SKILL FIX.
- [FIXED]  Monster level changed only the number, not HP/damage (found by: T0). Per-level scaling added (see above).
- [FIXED]  Left-click targeting hard to use in combat: corpses / your own pet / walls in front swallowed the click
           (found by: T1). New _pick_target_at() looks through them and allows a near miss. T3: "feels better after the
           last update".
- [FIXED]  Skills could be trained to the maximum at level 1 (found by: T2). Cap of 4 points per character level,
           tunable (skill_cap_per_level in Data/combat_balance.json); Skills page shows level / cap.
- [FIXED]  Skills in player_skills.json didn't feed the combat formulas (found by: T1). Data/skill_effects.json now maps each
           skill to what it does (weapon mastery -> ATK/damage/crit, dodge/parry/riposte/block, spell potency, concentration,
           meditation, athletics, bind wound...); skills with no mechanic to hook are listed in change_log.txt. Also fixed:
           swapping weapons now re-syncs the weapon skill, unarmed uses hand_to_hand, and offense/defense/weapon mastery
           and others now train from real use.

- [FIXED]  Being attacked while camping did not cancel the camp or stand you up (found by: T4). Any monster swing (hit or miss) now aborts /camp and stands you up.
